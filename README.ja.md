# vpad

[![CI](https://github.com/Wpaif/vpad/actions/workflows/ci.yml/badge.svg)](https://github.com/Wpaif/vpad/actions/workflows/ci.yml)
[![ライセンス: MIT](https://img.shields.io/badge/%E3%83%A9%E3%82%A4%E3%82%BB%E3%83%B3%E3%82%B9-MIT-blue.svg)](LICENSE)

[Português](README.md) · [English](README.en.md) · [Español](README.es.md) · [中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md)

スマートフォンを PC の仮想コントローラーにします。iPhone でページ（またはホーム画面のアプリ）を開くと、
タッチ操作がローカルネットワーク経由で送られ、PC 上の Rust 製サーバーが **仮想ゲームパッドまたはキーボード**
（uinput、Linux）を作成します。どのゲームやプログラムからも本物のデバイスとして認識されます。

- **プロファイル**: Xbox 360、DualShock 4、Switch Pro、キーボード。
- **マルチタッチ**、仮想アナログスティック、トリガー、十字キーに対応し、横向きとフルスクリーンで使えます。
- **遅延が見える**: ping/pong の計測に加え、スマートフォンの Wi-Fi が「眠る」場合のためのショート ping モードがあります。
- **ボタンのレイアウトを編集可能**: 移動、サイズ変更、非表示にでき、ボタンを一つずつ切り離すこともできます。
- **六つの言語**: ポルトガル語、英語、スペイン語、中国語（簡体字）、日本語、韓国語。スマートフォンの言語に合わせて選ばれ、パネルで切り替えられます。
- **ローカルネットワーク向けの安全設計**: 独自の認証局による HTTPS、コードによるペアリング、PC での承認。

> 現在の対象: **Linux**（Manjaro で動作確認）と **iPhone**（Safari / ホーム画面のアプリ）。
> Windows には対応していません。

## 必要なもの

PC 側:

- `uinput` モジュールが使え、`/dev/uinput` への書き込み権限がある Linux。
- サーバーをビルドするための Rust（2024 エディション、つまり 1.85 以降）。
- ページをビルドするための Node.js と npm（Vite + Svelte）。

スマートフォン側:

- Safari の使える iPhone。PC とスマートフォンは**同じローカルネットワーク**にいる必要があります。

`uinput` を有効にするには:

```sh
sudo modprobe uinput
# 自分のユーザーに権限を与える（ACL を使う例）:
sudo setfacl -m u:$USER:rw /dev/uinput
```

起動のたびにモジュールを自動で読み込むには、`/etc/modules-load.d/uinput.conf` を作成して `uinput` の 1 行を書きます。
PC を再起動しても権限を保ちたい場合は、ACL による権限（または udev ルール）も永続化する必要があります。

## インストール

プロジェクトをダウンロードしてフォルダーに移動します:

```sh
git clone https://github.com/Wpaif/vpad.git
# または SSH で: git clone git@github.com:Wpaif/vpad.git
cd vpad
```

ページは**バイナリに埋め込まれます**（release ビルドの場合。debug ではサーバーがディスクの `web/dist` を読みます）。
そのため、サーバーより先にページをビルドします:

```sh
cd web && npm install && npm run build && cd ..
cargo build --release
```

バイナリは `target/release/vpad` に作られます。`web/` の内容を変更したときは、
`npm run build` と `cargo build --release` をもう一度実行してください。

## 初めて使うとき

1. PC で**サーバーを起動**します:

   ```sh
   ./target/release/vpad
   ```

   ターミナルに QR コード、コントローラーのアドレス（`https://PCのIP:8443`）、認証局の SHA-256 フィンガープリント、
   証明書がカバーしている IP が表示されます。

2. **iPhone に証明書をインストール**します（一度だけ）。初回起動時にサーバーが独自の認証局を作成し、
   HTTP（`http://PCのIP:8080`）の設定ページを 5 分間開きます。あとで開き直すには、ターミナルで `c` を入力します。
   iPhone では（ページは端末の言語で開き、上部に言語を切り替えるリンクがあります。以下の iOS のメニュー名は日本語版 iOS のものです）:

   1. 設定ページを開き、**プロファイルをダウンロード** → **許可**をタップします。
   2. **設定 → プロファイルがダウンロードされました**を開き、証明書をタップして詳細を表示し、
      **SHA-256 フィンガープリント**が **PC のターミナル**に表示されているものと同じか確認します。確認できてから**インストール**をタップします。
   3. **設定 → 一般 → 情報 → 証明書信頼設定**を開き、**vpad** を信頼する設定をオンにします。

3. **端末をペアリング**します。ペアリングは初期状態で**閉じて**います。PC のターミナルで **Enter** を押すと、
   2 分間ペアリングが開き、30 秒ごとに変わる 6 桁のコードが表示されます。iPhone で `https://PCのIP:8443` を開いてコードを入力します。
   PC が承認を求めます。**`y`**（または **`s`**）で承認、**`k`**（または **`t`**）で承認して[キーボードモード](#キーボードモード)も許可、
   それ以外のキーで拒否です。

4. **アプリとしてインストール**します（任意、推奨）: Safari で**共有 → ホーム画面に追加**をタップします。
   アプリはフルスクリーンの横向きで開きます。

> ホーム画面のアプリには Safari とは**別の保存領域**があるため、単独でペアリングする必要があります。
> アプリを入れ直した場合は、もう一度ペアリングが必要です。ボタンのレイアウトは PC にも保存されているので、自動で戻ります。

## 普段の使い方

サーバーを起動したら、iPhone でアプリを開きます。Wi-Fi が切れても自動で再接続します。

- **ステータスのカプセル**（上部）: 遅延を表示します。タップするとパネルが開き、プロファイルの選択、
  統計（最新、平均、最小、最大、ジッター、損失）、ショート ping のボタン、レイアウトエディターへの入り口があります。
- **目のアイコン**（上部）: コントロールを隠したり表示したりします。
- **言語**: パネルに六つの言語のセレクターがあります。初回はスマートフォンの言語が使われます（翻訳のない言語の場合は英語）。
  切り替えるとページが再読み込みされます。
- **ショート ping**: 触れずにいると遅延が上がる場合は、iPhone の Wi-Fi が省電力に入っているためです。
  *ショート ping* をオンにすると 100 ms ごとに通知を送り、無線を起こしたままにします（スマートフォンのバッテリーを多く使います）。

サーバーのターミナルのコマンド（入力して Enter）:

| コマンド | 動作 |
| --- | --- |
| `Enter` | ペアリングを 2 分間開き、コードを表示する |
| `f` または `close` | ペアリングをすぐに閉じる |
| `c` | 証明書をインストールするページを 5 分間開く |
| `?` | ヘルプ |
| `s` または `y` / `t` または `k` / それ以外 | 承認の依頼に答える: はい / はい＋キーボードを許可 / 拒否 |

## コマンドラインのオプション

```
vpad [--perfil <xbox360|ds4|switch-pro|teclado>] [--porta <1-65535>]
     [--porta-https <1-65535>] [--parear]
vpad --dispositivos
vpad --revogar <id|todos>
vpad --permitir-teclado <id> | --negar-teclado <id>
```

オプション名はポルトガル語で、どの言語でも同じです。

| オプション | 意味 |
| --- | --- |
| `--perfil` | 最初のプロファイル（あとからスマートフォンで変更できます）。既定値: `xbox360` |
| `--porta` | 証明書の設定ページの HTTP ポート。既定値: `8080` |
| `--porta-https` | コントローラーの HTTPS ポート。既定値: `8443` |
| `--parear` | 起動時にペアリングを開く（ターミナルなしでサーバーを動かすときに便利） |
| `--dispositivos` | ペアリング済みの端末を一覧表示する（id、名前、有効期限、最終使用、キーボード） |
| `--revogar` | id で端末を一つ、または全部（`todos` または `all`）失効させる。サーバーの実行中でもすぐに反映される |
| `--permitir-teclado` / `--negar-teclado` | 端末のキーボードモードを許可または禁止する |

## ボタンのレイアウト

ステータスのカプセルをタップし、**レイアウトを編集…**をタップします。パネルが閉じ、グループに輪郭が付き、
画面の中央にバーが現れます。

- **移動**: グループをドラッグします。画面の外には出ず、iPhone のセーフエリアを守り、
  ほかのグループの端や中心に（ガイド線とともに）吸着します。
- **サイズ変更**: 右下の丸いハンドルをドラッグします。倍率は 0.5× から 2× までで、グループは端を越えて大きくならず、
  最も小さいボタンも 44 px を下回りません。
- **非表示**: **ボタン**を押すと、コントロールごとのスイッチの一覧が開きます。名前は使用中のプロファイルに従います
  （DualShock ではバツ、丸など。キーボードモードではキー）。
- **グループのロックを解除**: 各グループ（ボタンが二つ以上のもの）の右上の鍵アイコンで、ボタンを個別に動かせるようになります。
  ロックされたグループは一つのまとまりとして動きます。
- **不透明度**: バーのスライダーで、すべてのボタンを 100% から 20% まで透明にできます。押されたボタンは完全に表示されるので、
  不透明度が低くてもタッチが分かります。
- **元に戻す / キャンセル / 保存**: 書き込まれるのは**保存**だけです。**元に戻す**は標準のレイアウトに戻し（下書きの中で）、
  **キャンセル**は行った変更を破棄します。

編集中のタッチは PC には**送られません**。レイアウトは端末にも PC（`layout.json`）にも保存され、ペアリング済みの端末で共有されます。
アプリの入れ直しや、Safari とホーム画面のアプリの違いがあっても残ります。PC に接続できないときは端末だけに保存され、あとで送信されます。
パネルでその状態を確認できます。

## キーボードモード

**キーボード**プロファイルでは、ボタンが PC に文字を入力します。強力な機能なので、二つのロックがあります:

1. 端末に**キーボードの権限**が必要です。ペアリングの承認時（`k`）か、あとから `vpad --permitir-teclado <id>` で与えます。
2. モードを有効にするたびに、**PC がターミナルで確認を求めます**。

パネルの**キーを編集…**ボタンで各ボタンのキーを選びます。割り当ては `teclado.json` に保存されます。

## セキュリティ

vpad は家庭内のローカルネットワーク向けに作られていますが、ネットワークを信頼できないものとして扱います:

- **独自の認証局による HTTPS。** 認証局（CA）は PC で作成され、ローカルネットワークの名前と IP にしか有効ではありません（名前の制約）。
  その鍵が PC の外に出ることはありません。SHA-256 フィンガープリントはターミナルに表示されるので、プロファイルをインストールする前に確認できます。
- **ペアリングは初期状態で閉じています。** コードは 6 桁で 30 秒ごとに変わります。続けて間違えるとロックが段階的に長くなり
  （60 秒、300 秒、1800 秒）、ターミナルに IP 付きの警告が出ます。コードが正しくても、**PC の前にいる人が承認する**必要があります。
- **端末ごとに一つのトークン。** サーバーは SHA-256 ハッシュだけを保存します。トークンの有効期間は 90 日で、
  端末ごとに、ほかに影響せず失効させられます。
- **URL にトークンを含めません。** WebSocket はトークンをサブプロトコルで、API は `Authorization` ヘッダーで受け取ります。
- **サーバー側の防御。** `Host` と `Origin` を確認し（*DNS rebinding* や外部のページへの対策）、メッセージと本文のサイズを制限し、
  セキュリティヘッダー（厳格な CSP、`X-Frame-Options`、HSTS など）を送ります。スマートフォンから 6 秒間信号がない場合
  （1 秒に 1 回 ping を送ります）、接続は閉じられ、すべてのボタンが離されます。
- **キーボードは権限と確認が必要**です（上記参照）。

依存パッケージについては、`make audit` が RustSec の脆弱性データベースを確認します。

## 設定ファイル

すべて `$XDG_CONFIG_HOME/vpad/`（または `~/.config/vpad/`）にあります:

| ファイル | 内容 |
| --- | --- |
| `dispositivos.json` | ペアリング済みの端末（id、名前、トークンの**ハッシュ**、有効期限、キーボードの権限） |
| `dispositivos.vistos.json` | 各端末の最後の使用 |
| `teclado.json` | キーボードモードのキー割り当て |
| `layout.json` | ボタンのレイアウト。ペアリング済みの端末で共有される |
| `tls/` | 認証局とサーバー証明書（`ca-chave.pem` は CA の鍵です: **共有しないでください**） |

最初からやり直すには `vpad` フォルダーを削除します（プロファイルのインストールとペアリングをやり直す必要があります）。

## 開発

```sh
make test      # cargo test + npm test + フックのテスト
make hooks     # master への直接コミットを防ぐフックをインストールする
```

この節は概要だけです。プロジェクトの構成、バイナリプロトコル、翻訳の仕組み、貢献の流れ全体は
[ポルトガル語の README](README.md) にあります。要点は、機能ごとに一つのブランチ、テストを先に書くこと、
そして `master` は CI が通った pull request（`git push -u origin feature/<名前>`、`gh pr create --fill`、`gh pr merge --merge`）でのみ変更を受け付けることです。

## よくある問題

| 症状 | 対処 |
| --- | --- |
| `could not create the virtual controller` | モジュールを読み込み（`sudo modprobe uinput`）、自分のユーザーに `/dev/uinput` への書き込み権限を与える |
| Safari が接続は安全でないと警告する | 証明書のプロファイルがインストールされていないか、*証明書信頼設定*で信頼がオンになっていない |
| PC の IP が変わったあと証明書が使えなくなった | サーバーは起動時に証明書を自動で更新します。CA が入れ替わった場合はプロファイルをもう一度インストールしてください |
| 「ペアリングは閉じています」 | PC のターミナルで Enter を押して 2 分間開く |
| 「間違いが多すぎます」 | ロックが解除されるまで待つ（時間はメッセージに表示されます） |
| しばらく触れなかったあと、最初のキーが遅れて届く | パネルで**ショート ping**をオンにする。スマートフォンの Wi-Fi が眠っているためです |
| ホーム画面のアプリがまたペアリングを求める | Safari とは別の保存領域のため、アプリの中で一度ペアリングする |
| ホーム画面に古いアイコンが残っている | iOS は追加したときにアイコンを固定します。アプリを削除して追加し直してください |
