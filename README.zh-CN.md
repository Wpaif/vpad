# vpad

[![CI](https://github.com/Wpaif/vpad/actions/workflows/ci.yml/badge.svg)](https://github.com/Wpaif/vpad/actions/workflows/ci.yml)
[![许可证: MIT](https://img.shields.io/badge/%E8%AE%B8%E5%8F%AF%E8%AF%81-MIT-blue.svg)](LICENSE)

[Português](README.md) · [English](README.en.md) · [Español](README.es.md) · **中文** · [日本語](README.ja.md) · [한국어](README.ko.md)

把手机变成电脑的虚拟手柄。iPhone 打开一个网页（或主屏幕上的应用），通过局域网发送触控操作，
电脑上的 Rust 服务器会创建一个**虚拟手柄或键盘**（uinput，Linux），任何游戏或程序都会把它当作真实设备。

- **配置**：Xbox 360、DualShock 4、Switch Pro 和键盘。
- **多点触控**、虚拟摇杆、扳机键和方向键，支持横屏和全屏。
- **延迟一目了然**：ping/pong 延迟计；如果手机的 Wi-Fi “睡着了”，还有短 ping 模式。
- **可编辑的按键布局**：可以移动、缩放、隐藏按键，也可以逐个解锁单独移动。
- **六种语言**：葡萄牙语、英语、西班牙语、中文（简体）、日语和韩语，按手机语言自动选择，也可以在面板中切换。
- **适合局域网的安全设计**：使用自有证书颁发机构的 HTTPS、验证码配对，以及在电脑上批准。

> 当前支持：**Linux**（在 Manjaro 上测试）和 **iPhone**（Safari / 主屏幕应用）。
> 不支持 Windows。

## 系统要求

电脑端：

- Linux，已加载 `uinput` 模块，并且对 `/dev/uinput` 有写入权限。
- Rust（2024 版本，即 1.85 或更新）用于编译服务器。
- Node.js 和 npm 用于编译网页（Vite + Svelte）。

手机端：

- 装有 Safari 的 iPhone。电脑和手机必须在**同一个局域网**内。

启用 `uinput`：

```sh
sudo modprobe uinput
# 给你的用户授权（使用 ACL 的示例）：
sudo setfacl -m u:$USER:rw /dev/uinput
```

要让模块每次开机自动加载，请创建 `/etc/modules-load.d/uinput.conf`，内容为一行 `uinput`。
如果希望重启电脑后权限依然有效，ACL 权限（或 udev 规则）也需要持久化。

## 安装

### 现成的可执行文件（Linux x86_64 / aarch64）

如果你只想使用它，请从[最新版本](https://github.com/Wpaif/vpad/releases/latest)下载压缩包（`vpad-X.Y.Z-linux-x86_64.tar.gz`，旁边有对应的 `.sha256` 文件），核对校验和并解压。不需要 Rust 或 Node，但仍然需要[系统要求](#系统要求)中的 `uinput` 设置。提供 **x86_64**（Intel/AMD）和 **aarch64**（64 位 ARM，例如运行 64 位系统的 Raspberry Pi 4/5）两种压缩包：使用 ARM 时，请把名称中的 `x86_64` 换成 `aarch64`。 之后请按[首次使用](#首次使用)操作。

```sh
sha256sum -c vpad-X.Y.Z-linux-x86_64.tar.gz.sha256
tar xzf vpad-X.Y.Z-linux-x86_64.tar.gz
cd vpad-X.Y.Z-linux-x86_64
./vpad
```

### 从源码编译

下载项目并进入目录：

```sh
git clone https://github.com/Wpaif/vpad.git
# 或使用 SSH：git clone git@github.com:Wpaif/vpad.git
cd vpad
```

网页会**嵌入到可执行文件中**（release 构建时；debug 构建时服务器从磁盘读取 `web/dist`），
所以要先编译网页，再编译服务器：

```sh
cd web && npm install && npm run build && cd ..
cargo build --release
```

可执行文件位于 `target/release/vpad`。如果修改了 `web/` 中的任何内容，请重新运行
`npm run build` 和 `cargo build --release`。

## 首次使用

1. 在电脑上**启动服务器**：

   ```sh
   ./target/release/vpad
   ```

   终端会显示二维码、手柄地址（`https://电脑IP:8443`）、证书颁发机构的 SHA-256 指纹，
   以及证书覆盖的 IP 地址。

2. **在 iPhone 上安装证书**（只需一次）。首次运行时，服务器会创建自己的证书颁发机构，并通过
   HTTP（`http://电脑IP:8080`）开放一个配置页面 5 分钟。之后想再次打开，请在终端输入 `c`。
   在 iPhone 上（页面会以设备的语言显示，顶部有切换语言的链接；下面的 iOS 菜单名称是中文版 iOS 的名称）：

   1. 打开配置页面，点按**下载描述文件** → **允许**。
   2. 在**设置 → 已下载描述文件**中点按证书，再点按**更多详细信息**，核对 **SHA-256 指纹**
      是否与**电脑终端**中显示的一致。确认后再点按**安装**。
   3. 在**设置 → 通用 → 关于本机 → 证书信任设置**中，为 **vpad** 开启信任。

3. **配对设备。**配对默认是**关闭**的。在电脑终端按 **Enter**：配对会开启 2 分钟，并显示一个每 30 秒变化
   一次的 6 位验证码。在 iPhone 上打开 `https://电脑IP:8443` 并输入验证码。电脑会请求你批准：
   **`y`**（或 **`s`**）表示批准，**`k`**（或 **`t`**）表示批准并同时开启[键盘模式](#键盘模式)，按其他任意键则拒绝。

4. **安装为应用**（可选，推荐）：在 Safari 中点按**分享 → 添加到主屏幕**。应用会以全屏和横屏方式打开。

> 主屏幕应用有**独立的存储空间**，与 Safari 分开：需要单独配对。如果重新安装应用，需要重新配对；
> 按键布局会自动恢复，因为它同时保存在电脑上。

## 日常使用

服务器运行后，在 iPhone 上打开应用。Wi-Fi 断开时它会自动重新连接。

- **状态胶囊**（顶部）：显示延迟。点按它会打开面板，里面有配置选择、统计信息（最近、平均、最小、
  最大、抖动、丢包）、短 ping 按钮和布局编辑器入口。
- **眼睛图标**（顶部）：隐藏或显示控件。
- **语言**：面板中有包含六种语言的选择器。首次打开时使用手机的语言（使用没有翻译的语言时显示英语）；
  切换语言会重新加载页面。
- **短 ping**：如果停止触控后延迟升高，那是 iPhone 的 Wi-Fi 进入了省电模式。开启*短 ping* 会每 100 ms
  发送一次消息，让无线电保持唤醒（会多消耗手机电量）。

服务器终端的命令（输入后按 Enter）：

| 命令 | 作用 |
| --- | --- |
| `Enter` | 开启配对 2 分钟并显示验证码 |
| `f` 或 `close` | 立即关闭配对 |
| `c` | 开放 5 分钟用于安装证书的页面 |
| `?` | 帮助 |
| `s` 或 `y` / `t` 或 `k` / 其他 | 回复批准请求：同意 / 同意并开启键盘 / 拒绝 |

## 命令行选项

```
vpad [--perfil <xbox360|ds4|switch-pro|teclado>] [--porta <1-65535>]
     [--porta-https <1-65535>] [--parear]
vpad --dispositivos
vpad --revogar <id|todos>
vpad --permitir-teclado <id> | --negar-teclado <id>
```

选项名称是葡萄牙语，在所有语言中都相同。

| 选项 | 含义 |
| --- | --- |
| `--perfil` | 初始配置（手机之后可以更改）。默认：`xbox360` |
| `--porta` | 证书配置页面的 HTTP 端口。默认：`8080` |
| `--porta-https` | 手柄的 HTTPS 端口。默认：`8443` |
| `--parear` | 启动时开启配对（服务器在没有终端的环境下运行时很有用） |
| `--dispositivos` | 列出已配对的设备（id、名称、有效期、最近使用、键盘） |
| `--revogar` | 按 id 撤销某个设备，或撤销全部（`todos` 或 `all`）。即使服务器正在运行也会立即生效 |
| `--permitir-teclado` / `--negar-teclado` | 允许或禁止某个设备使用键盘模式 |

## 按键布局

点按状态胶囊，再点按**编辑布局…**。面板会关闭，各分组出现轮廓，屏幕中央出现一个工具栏。

- **移动**：拖动一个分组。它不会超出屏幕，会避开 iPhone 的安全区域，并且会（带辅助线）吸附到其他分组的边缘和中心。
- **缩放**：拖动右下角的圆形手柄。缩放范围是 0.5× 到 2×，分组不会超出边缘，最小的按键也不会小于 44 px。
- **隐藏**：**按钮**按钮会打开一个列表，每个控件一个开关。名称会跟随当前配置（DualShock 上是叉号、圆圈……；键盘模式下是按键）。
- **解锁分组**：每个分组（包含多个按键的）右上角的挂锁可以将其解锁，从而单独移动每个按键。锁定的分组整体移动。
- **不透明度**：工具栏中的滑块可以让所有按键变得更透明，从 100% 到 20%。被按下的按键会完整显示，
  这样即使不透明度很低，你也能看到触控。
- **恢复默认 / 取消 / 保存**：只有**保存**才会写入。**恢复默认**会回到默认布局（仅在草稿中），**取消**会放弃所做的修改。

编辑期间，触控**不会**发送到电脑。布局会保存在设备上，也保存在电脑上（`layout.json`），由已配对的设备共享：
重新安装应用后仍然保留，Safari 和主屏幕应用之间也一样。与电脑断开连接时，布局只保存在设备上，稍后再发送；面板会显示它当前的状态。

## 键盘模式

在**键盘**配置下，按键会在电脑上输入文字。因为这很强大，所以有两道锁：

1. 设备必须有**键盘权限**，可以在批准配对时授予（`k`），也可以之后用 `vpad --permitir-teclado <id>` 授予。
2. 每次启用该模式时，**电脑都会在终端中请求确认**。

面板中的**编辑按键…**按钮用于选择每个按钮对应的按键；映射保存在 `teclado.json` 中。

## 安全

vpad 面向家庭局域网设计，但把网络视为不可信：

- **使用自有证书颁发机构的 HTTPS。**证书颁发机构（CA）在电脑上创建，只对局域网的名称和 IP 有效（名称限制）。
  它的密钥不会离开电脑。SHA-256 指纹会显示在终端中，方便你在安装描述文件前核对。
- **配对默认关闭。**验证码为 6 位，每 30 秒变化一次；连续出错会导致不断加长的锁定（60 秒、300 秒、1800 秒），
  并在终端中发出带 IP 的警报。即使验证码正确，**电脑前的人也必须批准**。
- **每个设备一个令牌。**服务器只保存 SHA-256 哈希；令牌有效期为 90 天，每个设备都可以单独撤销而不影响其他设备。
- **URL 中没有令牌。**WebSocket 通过子协议接收令牌，API 通过 `Authorization` 头接收令牌。
- **服务器端防护。**检查 `Host` 和 `Origin`（防范 *DNS rebinding* 和外部网页），限制消息和请求体的大小，
  并发送安全头（严格的 CSP、`X-Frame-Options`、HSTS 等）。如果 6 秒内没有收到手机的信号
  （它每秒发送一次 ping），连接会被关闭，所有按键都会被释放。
- **键盘需要权限和确认**（见上文）。

对于依赖项，`make audit` 会查询 RustSec 漏洞数据库。

## 配置文件

所有内容都在 `$XDG_CONFIG_HOME/vpad/`（或 `~/.config/vpad/`）中：

| 文件 | 内容 |
| --- | --- |
| `dispositivos.json` | 已配对的设备（id、名称、令牌的**哈希**、有效期、键盘权限） |
| `dispositivos.vistos.json` | 每个设备最近一次的使用时间 |
| `teclado.json` | 键盘模式的按键映射 |
| `layout.json` | 按键布局，由已配对的设备共享 |
| `tls/` | 证书颁发机构和服务器证书（`ca-chave.pem` 是 CA 的密钥：**不要分享**） |

想从头开始，请删除 `vpad` 文件夹（你需要重新安装描述文件并重新配对）。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `could not create the virtual controller` | 加载模块（`sudo modprobe uinput`），并给你的用户授予 `/dev/uinput` 的写入权限 |
| Safari 提示连接不安全 | 没有安装证书描述文件，或者还没有在*证书信任设置*中开启信任 |
| 电脑更换 IP 后证书失效 | 服务器启动时会自动更新证书；如果 CA 被更换，请重新安装描述文件 |
| “配对已关闭” | 在电脑终端按 Enter，开启 2 分钟 |
| “错误次数过多” | 等待锁定结束（时间会显示在提示中） |
| 暂停后的第一次按键延迟到达 | 在面板中开启**短 ping**；这是手机的 Wi-Fi 在休眠 |
| 主屏幕应用再次要求配对 | 它的存储与 Safari 分开；请在应用内配对一次 |
| 主屏幕上仍然是旧图标 | iOS 在添加时就固定了图标：删除应用后重新添加 |
